SimplClip

Быстрая локальная история буфера обмена для Windows.

Fast, local clipboard history for Windows.

SimplClip запоминает скопированный текст, ссылки, изображения и файлы и возвращает их по одному сочетанию клавиш. История хранится на вашем компьютере, а нужный элемент находится поиском и вставляется прямо в то приложение, где вы работаете.

SimplClip remembers the text, links, images and files you copy and brings them back with a single shortcut. Your history stays on your PC, and you find the item you need with search and paste it straight into the application you are working in.

Вопросы и ответы Questions and answers

Частые вопросы Frequently asked questions

Коротко о том, что SimplClip делает сегодня и что запланировано к коммерческому релизу.

A short summary of what SimplClip does today and what is planned for the commercial release.

Что такое SimplClip? What is SimplClip?

SimplClip — менеджер буфера обмена для Windows. Он ведёт историю того, что вы копируете, и открывает её в компактном всплывающем окне, чтобы вы могли вставить нужный элемент, а не копировать его заново.

SimplClip is a clipboard manager for Windows. It keeps a history of what you copy and opens it in a compact popup, so you can paste the item you need instead of copying it again.

Какая версия доступна сейчас? What version is available now?

SimplClip 0.1.0 Alpha для Windows 10/11 (x64). Это первая публичная сборка: она уже опубликована и доступна для загрузки, но остаётся альфа-версией.

SimplClip 0.1.0 Alpha for Windows 10/11 (x64). This is the first public build: it is published and available to download, but it is still an alpha.

Где хранится история буфера обмена? Where is clipboard history stored?

История хранится локально, на том компьютере, где установлен SimplClip.

The history is stored locally, on the computer where SimplClip is installed.

Выгружаются ли данные буфера обмена в облако? Is clipboard data uploaded to the cloud?

Нет. SimplClip не отправляет историю буфера обмена на серверы EmDiSoftware. Она остаётся на вашем компьютере.

No. SimplClip does not upload clipboard history to EmDiSoftware servers. It stays on your PC.

Какие типы данных поддерживаются? What data types are supported?

Текст, ссылки, изображения и файлы.

Text, links, images and files.

Как открыть SimplClip? How do I open SimplClip?

Сочетанием клавиш Ctrl + Shift + V. Всплывающее окно открывается поверх того приложения, в котором вы работаете.

With the Ctrl + Shift + V shortcut. The popup opens on top of the application you are working in.

Что такое Direct Paste? What is Direct Paste?

SimplClip открывается, пока вы работаете в другом приложении. Вы выбираете элемент из истории, и SimplClip может вставить это содержимое обратно в приложение, которое было активным до вызова. Приложения Windows принимают вставку по-разному, поэтому совместимость со всеми программами без исключения не гарантируется.

SimplClip opens while you are working in another application. You choose an item from the history, and SimplClip can paste that content back into the application that was active before. Windows applications accept pasted content in different ways, so compatibility with every program is not guaranteed.

Что делает Ctrl+Enter? What is Copy-only (Ctrl+Enter)?

Это режим «копировать без вставки». Enter вставляет выбранный элемент в ранее активное приложение, а Ctrl + Enter только возвращает его в буфер обмена — вставите сами, когда понадобится.

It is copy without pasting. Enter pastes the selected item into the previously active application, while Ctrl + Enter only puts it back on the clipboard, so you can paste it yourself later.

Можно ли исключить приложение из захвата? Can I exclude an application from capture?

Да. Приложение можно добавить в исключения в настройках приватности — скопированное в нём не будет записываться в историю. Там же можно исключить поддерживаемые категории, такие как изображения и файлы, или отключить захват полностью.

Yes. An application can be added to the exclusion list in the privacy settings — whatever you copy inside it will not be recorded. The same settings let you exclude supported categories such as images and files, or disable capture entirely.

SimplClip работает в фоне? Does SimplClip run in the background?

Да. Чтобы вести историю и отвечать на сочетание клавиш, SimplClip должен быть запущен. Всплывающее окно появляется только тогда, когда вы его вызываете.

Yes. To keep the history and respond to the shortcut, SimplClip needs to be running. The popup appears only when you call it.

Что такое лицензия Alpha Tester? What is an Alpha Tester license?

Это отдельный тип лицензии для этапа тестирования: он привязан к Device ID компьютера и проверяется офлайн. Это единственный тип лицензии, который поддерживает версия 0.1.0 Alpha, и он не продаётся публично. Лицензия Personal — часть планируемой коммерческой версии и с Alpha Tester не связана.

It is a separate license type for the testing stage: it is tied to the PC Device ID and verified offline. It is the only license type 0.1.0 Alpha supports, and it is not sold publicly. The Personal license belongs to the planned commercial release and is unrelated to Alpha Tester.
