SimplPass

Защита папок паролем прямо на вашем компьютере. Папка остаётся на месте, имена файлов видны в Проводнике, а их содержимое зашифровано.

Password-protected folders right on your computer. The folder stays where it is and file names stay visible in File Explorer, while the contents are encrypted.

Windows 10/11 x64 Free 1.0.1

Главное о приложении

Application highlights

Защита на месте

Protection in place

Любая обычная папка защищается там, где лежит: без файлов-контейнеров и букв дисков. Программы и привычки продолжают работать.

Any regular folder is protected where it is: no container files and no drive letters. Your apps and habits keep working.

Имена видны, содержимое закрыто

Names visible, contents locked

В заблокированной папке видны имена файлов, а их содержимое зашифровано: AES-256-GCM, ключ из пароля по Argon2id.

A locked folder shows its file names while the contents stay encrypted: AES-256-GCM with a key derived from your password by Argon2id.

Понятный запрос пароля

A clear password prompt

Окно пароля показывает, какая программа открывает какой файл и из какой папки, и предупреждает о включённом Caps Lock.

The password prompt shows which app is opening which file from which folder, and warns when Caps Lock is on.

Из Проводника и одной кнопкой

From File Explorer or one click

Защитите папку из меню Проводника «Защитить с SimplPass» и блокируйте её одной кнопкой, когда закончили.

Protect a folder from the File Explorer menu with “Protect with SimplPass” and lock it with one click when you are done.

Состояние видно сразу

State at a glance

«Защищено», «Открыто», «Операция прервана» — у каждого состояния свой цвет и значок, а у прерванной операции есть безопасное восстановление.

Protected, Open, Operation interrupted — each state has its own colour and icon, and an interrupted operation has safe recovery.

Блокировка вместе с Windows

Locks with Windows

Когда Windows блокирует сеанс, SimplPass старается заблокировать открытые папки сам.

When Windows locks your session, SimplPass tries to lock open folders itself.

Родной вид Windows 11

Native Windows 11 look

Светлая и тёмная тема по настройкам Windows, интерфейс на русском и английском языках.

Light and dark theme following Windows, with a Russian and English interface.

Только на вашем компьютере

Only on your computer

Без интернета, учётной записи, серверов и телеметрии. Забытый пароль восстановить нельзя — храните его надёжно.

No internet, account, servers or telemetry. A forgotten password cannot be recovered, so keep it safe.
